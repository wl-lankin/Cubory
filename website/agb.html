Cubory ist eine Desktop-Anwendung für macOS, Windows und Linux zum Anzeigen von CAD-Dateien (u. a. DXF, STEP, IGES, STL, OBJ). Die Software wird in einer kostenlosen Version („Free") und einer kostenpflichtigen Version („Pro") mit erweitertem Funktionsumfang angeboten. Der jeweilige Funktionsumfang ergibt sich aus der Beschreibung auf cubory.app zum Zeitpunkt des Vertragsschlusses. Neue Konten erhalten einmalig eine 7-tägige kostenlose Pro-Testphase; danach wechselt das Konto automatisch und ohne Kosten auf Free.
